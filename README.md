# IMGUI Control System

A cross-platform C++ application using OpenGL, ImGui, GLFW, and Boost.Beast for WebSocket support. Builds on both Windows and Linux with consistent dependencies managed through Git submodules.

## Prerequisites

### Windows
- **Git** - For version control and submodule management
- **CMake 3.20+** - Build system generator
- **Visual Studio 2022** - C++ compiler (Community edition works fine)
  - Make sure "Desktop development with C++" workload is installed

### Linux (Ubuntu/Debian)
- **Build tools:**
  ```bash
  sudo apt update
  sudo apt install build-essential cmake git
  ```

- **X11 development libraries** (required by GLFW):
  ```bash
  sudo apt install libx11-dev libxrandr-dev libxinerama-dev libxcursor-dev libxi-dev
  ```

- **OpenGL development libraries:**
  ```bash
  sudo apt install libgl1-mesa-dev
  ```

## Quick Start

### First Time Setup

#### Option 1: Clone with submodules (Recommended)
```bash
git clone --recurse-submodules <repository-url>
cd <project-directory>

# Windows:
setup.bat

# Linux:
chmod +x setup.sh
./setup.sh
```

#### Option 2: Setup existing clone
If you've already cloned without `--recurse-submodules`:

```bash
# Windows:
setup.bat

# Linux:
chmod +x setup.sh
./setup.sh
```

**Note:** The setup script may take 5-10 minutes on first run as it initialises Boost submodules and generates headers.

## Building

### Windows

```cmd
mkdir build
cd build
cmake -G "Visual Studio 17 2022" ..
cmake --build . --config Release
```

Run the application:
```cmd
.\Release\app.exe
```

### Linux

```bash
mkdir -p build
cd build
cmake ..
make -j$(nproc)
```

Run the application:
```bash
./app
```

## What the Setup Script Does

The setup script automates dependency configuration:

1. **Initialises Git submodules** - Downloads Boost and GLFW source code
2. **Configures Boost 1.83.0** - Checks out the correct version and initialises its nested submodules
3. **Generates Boost headers** - Runs `bootstrap` and `b2 headers` to create the unified header structure
4. **Configures GLFW 3.4** - Checks out the correct version for consistent cross-platform window management

## Dependencies

### Managed via Git Submodules
- **Boost 1.83.0** - Header-only libraries for Beast (WebSocket) and ASIO (networking)
- **GLFW 3.4** - Cross-platform window and input management

### Included in Repository
- **GLAD** - OpenGL loader (generated for OpenGL 3.3+ Core Profile)
- **Dear ImGui** - Immediate mode GUI library

### System Libraries
- **OpenGL** - Graphics API (system-provided)
- **X11** - Linux window system (system-provided)

## Troubleshooting

### "Boost submodule not found" or "Cannot open include file: 'boost/beast/websocket.hpp'"

**Solution:** The Boost headers haven't been generated yet.

```bash
# Run the setup script again
# Windows:
setup.bat

# Linux:
./setup.sh
```

The script must run `b2 headers` to create the unified `boost/` include directory.

### "CMake Error: could not find git"

**Solution:** Install Git and ensure it's in your PATH.

### Linux: "undefined reference to 'glfwGetPlatform'"

**Solution:** This shouldn't happen with the submodule approach. If it does, clean your build:
```bash
rm -rf build
mkdir build
cd build
cmake ..
make
```

### Windows: Build errors about missing Visual Studio components

**Solution:** Install the "Desktop development with C++" workload in Visual Studio Installer.

### Boost compilation takes forever

**Solution:** This is normal on first run. The `b2 headers` command processes all Boost libraries. Subsequent builds will be much faster as headers are already generated.

## For Contributors

When cloning this repository, always use:
```bash
git clone --recurse-submodules <repository-url>
```

Then run the setup script for your platform.

If you pull updates that change the submodules:
```bash
git submodule update --init --recursive
# Then run setup script again if needed
```

## Updating Dependencies

### To update Boost or GLFW versions:

1. Edit the setup script and change the git checkout line
2. Run the setup script
3. Test the build on both platforms
4. Commit the setup script changes

Example:
```bash
# In setup.sh or setup.bat, change:
git checkout boost-1.83.0
# To:
git checkout boost-1.84.0
```

## Platform-Specific Notes

### Windows
- Uses precompiled GLFW on Windows (optional - can also use submodule)
- MSVC compiler with `/MP` flag for parallel compilation
- Boost ASIO requires Windows Sockets (ws2_32, wsock32, mswsock)

### Linux
- Builds GLFW from source (submodule)
- Uses X11 backend (Wayland support disabled for simplicity)
- Boost ASIO requires pthread for threading
- Can optionally use system Boost if available
